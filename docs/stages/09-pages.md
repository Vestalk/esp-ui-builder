# Етап 09 — Кілька сторінок у генерації

**Мета:** кожна сторінка проєкту — окремий модуль; розробник сам вирішує, коли яку показувати.

**Залежить від:** 03
**Оцінка:** 2–3 дні

## Специфікація
- Файл на сторінку: `ui_<сторінка>.py` з власними `DEFAULTS` і класом `UI`.
- Спільні для всіх сторінок: `ui_display.py`, `ui_st7789.py`, `ui_fonts.py` (об'єднаний набір гліфів), `img/`.
- Назва сторінки — ідентифікатор Python; заборонені `display`, `st7789`, `fonts`.
- Параметри — свої в кожної сторінки; однакові назви на різних сторінках дозволені.
- Після перемикання сторінки — завжди повна перемальовка (`draw()`).

## `main.py` (приклад, не логіка перемикання)
```python
d = ui_display.create()
pages = {
    'main': (ui_main.UI(d), dict(ui_main.DEFAULTS)),
    'settings': (ui_settings.UI(d), dict(ui_settings.DEFAULTS)),
}
current = 'main'
ui, p = pages[current]
ui.draw(p)

def show(name):          # викликає ваш код: кнопка, таймер, подія
    global current, ui, p
    current = name
    ui, p = pages[name]
    ui.draw(p)
```

## Критерії готовності
- [ ] Проєкт з двома сторінками генерує два модулі; перемикання з `main.py` працює на платі.
- [ ] CLI: `espui generate` без `--page` генерує всі сторінки.
- [ ] Спільний `ui_fonts.py` містить гліфи всіх сторінок.
