# Етап 14 — GUI: сеанси і генерація

**Мета:** не втрачати роботу і отримувати файли для плати з вікна програми.

**Залежить від:** 12, 09
**Оцінка:** 4–5 днів

## Сеанс
- [ ] Автозбереження у файл проєкту `.espui` через ~1,5 с після зміни (лише якщо дані змінились); Ctrl/⌘+S — одразу.
- [ ] Для нового, ще не збереженого проєкту — автозбереження в папку даних програми; при наступному запуску
      пропозиція відновити.
- [ ] Зберігається все: сторінки, параметри, тестові значення, дисплей, масштаб, бібліотека картинок.
- [ ] Меню «Файл»: Новий (з підтвердженням), Відкрити, Зберегти, Зберегти як, Імпорт з `.espui.json`
      (експорт з макета), Останні проєкти.
- [ ] Рядок стану: «Збережено о 01:20» / «Зберігаю…» / помилка.

## Генерація
- [ ] «▶ Згенерувати»: вибір папки (запам'ятовується для проєкту), перевірка проєкту, запис файлів.
- [ ] Вікно результату: список файлів (`ui_display.py`, файл драйвера, `ui_fonts.py`, `ui_<сторінка>.py` для кожної сторінки,
      `main.py`, `.vscode/settings.json`, `img/*.bin`) з розмірами; перегляд будь-якого файлу; кнопка «Відкрити папку».
- [ ] Картинки конвертуються і записуються в `img/` автоматично в тій самій генерації (етап 08); `.vscode/settings.json`
      налаштовує MicroPico так, щоб «Upload project» завантажував і `.py`, і `.bin`.
- [ ] Підказка: відкрити папку у VS Code і завантажити командою MicroPico «Upload project to Pico».
- [ ] Не перезаписувати `main.py`, якщо його змінив розробник (питати або писати `main.example.py`).

## Критерії готовності
- [ ] Закриття програми без збереження й повторне відкриття повертають той самий стан.
- [ ] Згенерована папка заливається на плату й працює без правок.

## Тести
- Збереження/відновлення (round-trip), пошкоджений файл, імпорт з макета.
- Генерація у тимчасову папку, перевірка переліку файлів і захисту `main.py`.
