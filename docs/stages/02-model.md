# Етап 02 — Модель даних і формат `.espui`

**Мета:** описати проєкт як дані, з валідацією і збереженням, і винести всі формули обчислення властивостей
в один модуль, яким користуватимуться і генератор, і прев'ю в GUI.

**Залежить від:** 00
**Оцінка:** 1 тиждень

## Результат
- `core/models.py`, `core/serializer.py`, `core/evaluate.py`, `core/colors.py`, `displays/gmt020_02.yaml`.
- JSON-схема `docs/espui.schema.json` (генерується з моделей).

## Модель

### Project
`schema` (версія), `display`, `pages[]`, `images{}` — бібліотека картинок проєкту: **оригінали вбудовані у файл проєкту**
(base64) разом з назвою й шляхом на платі; для анімацій (GIF, відео) — масив кадрів і `delay_ms`, шлях — папка `/img/<назва>/`, тож `.espui` самодостатній і генерація не потребує зовнішніх файлів.

### Display
`model` = `GMT020-02-8B`, `rotation` 0–3 (1/3 → 320×240, 0/2 → 240×320), `spi_hz`,
`mcu` ∈ {`esp32s3` (за замовчуванням), `esp32`, `esp32c3`}, `driver` ∈ {`builtin` (`ui_st7789`), `st7789py`} — лише Python-драйвери,
`pins {sck, mosi, dc, cs, rst, bl|null}`.
Валідація пінів за чипом: ESP32-S3 — 0–48, не 19/20 (USB); ESP32 — 0–39, не 6–11 (флеш), 34–39 лише вхід;
ESP32-C3 — 0–21, не 12–19 (флеш, USB); без повторів. Драйвер має підтримувати вибраний чип.

### Page
`name` (ідентифікатор Python; не `display`, `st7789`, `fonts`; унікальний), `background`,
`parameters[]`, `widgets[]` (порядок = порядок шарів, перший — найнижчий).

### Parameter
| Тип | Поля | За замовчуванням |
|---|---|---|
| `float` / `int` | `min < max` (для `int` цілі) | у межах |
| `bool` | — | `false` |
| `str` | `max_len` 2–128 | коротше за `max_len` |
| `enum` | `values[]` ≥ 2, унікальні | один з варіантів |
| `series` | `max_points` 2–256, `x_kind` = `number` \| `label` (≤ 7 символів), `min < max` (межі Y) | список мап `[{x: y}, …]` |

`name` — ідентифікатор Python, не зарезервоване слово, унікальний у межах сторінки.

### Widget (спільні поля)
**Статичні (базові) значення** — лише константи, без посилань на параметри, крім джерела даних `bind`:
`id`, `type` ∈ {rect, circle, line, text, value, bar, arc, image, chart}, `x`, `y`, `w`, `h`, `color`,
`font` ∈ {serif, mono, pixel} (text, value, bar, arc, chart; за замовчуванням serif), `font_size` (8–72 px; для text, value, bar, arc), `bind` (джерело даних), `format`,
`opacity` (0–100 %, 100 — видно повністю), `rotation_deg` (не для `chart`),
`pivot` = пресет (`center`, кути, середини сторін) | `{x, y}` від лівого верхнього кута — **константа**.

**Усе, що залежить від параметрів, — лише в `rules[]`** (блок «Умови»), два види записів:
- `condition`: `{if: [param, op, value], set: prop, to: value}` — дискретна зміна;
  `prop` ∈ {`color`, `text` (лише text/value), `visible`, `opacity`, `angle` (не для chart), `x`, `y`}.
- `mapping`: `{param, prop, at_min, at_max}` — лінійна залежність від числового параметра;
  `prop` ∈ {`opacity`, `angle` (не для chart), `x`, `y`}.

Порядок обчислення: базові значення → усі `mapping` → усі `condition` зверху вниз (нижня перемагає).
Окремих полів `show`, «прозорість з параметра», «позиція з параметра», «кут з параметра» немає:
старі проєкти мігруються в `rules[]` при відкритті.
Специфічні: `image {file | null, fit: contain|cover|fill, play: loop|once}`, `chart {axis_x, axis_y, y_min, y_max, style, grid}`.

Допустимі прив'язки (`bind`): text — будь-який, крім series; value/bar/arc — float/int; image — str; chart — series;
rect/circle/line — немає.

## `core/evaluate.py`
Чисті функції без Qt і без MicroPython, покриті тестами:
- `lin(param, value, a, b)` — лінійне відображення з обмеженням 0…1.
- `effective(widget, values) -> EffectiveWidget`: базові значення → `mapping` → `condition` (нижня перемагає);
  результат — позиція, видимість, колір, текст, непрозорість, кут, точка повороту в абсолютних координатах.
- `format_value(fmt, value)` — підмножина printf: `%s`, `%d`, `%.Nf`, `%%`.
- `parse_series(text, param)` і `series_to_text()` для поля тестових значень `x:y; x:y`.

## Сумісність
- `serializer.load()` мігрує старі версії `schema`; невідомі поля зберігає.
- Імпорт приймає файли `*.espui` і `*.espui.json` (експорт з макета).

## Тести
- Валідація кожного типу параметра (граничні значення, неправильні назви, ключові слова).
- `effective()` для таблиці випадків: залежності при мін/макс/посередині, умови в різному порядку, умова поверх залежності.
- Міграція старих полів (`show`, прозорість/позиція/кут з параметра) у `rules[]`.
- `parse_series`: формати, повтори ключів, перевищення `max_points`, мітки > 7 символів.
