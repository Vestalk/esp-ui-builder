# Етап 03 — Генератор: базові елементи, `draw` / `update`, CLI

**Мета:** з файлу `.espui` отримати робочі модулі MicroPython для однієї сторінки з базовими елементами
і перевірити їх на платі. Це перший кінцевий результат проєкту, ще без GUI.

**Залежить від:** 01, 02
**Оцінка:** 1,5 тижня

## Результат
- `generators/micropython/generator.py`, шаблони `templates/*.py.j2`, `runtime/` (драйвер з етапу 01, хелпери малювання).
- CLI: `espui generate project.espui -o out/ [--page main]`.
- `examples/weather.espui` і згенерована з нього папка, перевірена на платі.

## Що генерується
| Файл | Вміст |
|---|---|
| `ui_display.py` | `PINS`, `SPI_HZ`, `ROTATION`, адаптер `Display`, `create()` для **вибраного драйвера** |
| файл драйвера | `ui_st7789.py` (вбудований) або `st7789py.py` — завжди Python, завжди в папці генерації |
| `ui_main.py` | `DEFAULTS` (словник параметрів з коментарями типів і меж), клас `UI` |
| `main.py` | приклад: `ui.draw(p)`, цикл з `ui.update(p)` |

### API класу `UI`
```python
ui = ui_main.UI(ui_display.create())
p = dict(ui_main.DEFAULTS)
ui.draw(p)          # повна перемальовка
p["temperature"] = 23.4
ui.update(p)        # лише змінене
ui.set_temperature(22.0)   # set_<параметр>() для кожного параметра
```

## Елементи цього етапу
Прямокутник, коло (еліпс), лінія, текст (поки вбудований шрифт `framebuf` 8×8, кирилиця — етап 07),
число, смуга прогресу, дуга. Формат — `core.evaluate.format_value`.

## Механіка оновлення
- Для кожного елемента — метод `_draw_<id>(p)` і список залежностей (параметри, від яких він залежить).
- `update(p)` порівнює з попередніми значеннями (копія словника) і збирає «брудні» елементи.
- **Перекриття:** для кожної брудної області перемальовуються всі елементи, що її перетинають, у порядку шарів,
  у спільний `framebuf` цієї області, і лише потім область пишеться в дисплей. Це потрібно для правильного
  накладання й для прозорості (етап 05).
- Буфер області обмежений (значення з етапу 01); більші області малюються горизонтальними смугами.
- Фон сторінки — колір `background`.

## Критерії готовності
- [ ] `examples/weather.espui` після генерації й завантаження через MicroPico показує екран як у макеті.
- [ ] `update()` після зміни одного параметра пише в дисплей лише область відповідних елементів
      (перевірка на фейковому дисплеї: лог викликів `blit`).
- [ ] Час `update()` для зміни одного числа ≤ 25 мс на платі.
- [ ] Згенерований код проходить `ruff` і запускається на unix-порті MicroPython.
