# Етап 11 — GUI: редагування елементів і шари

**Мета:** збирати сторінку мишею: додавати, рухати, змінювати розмір, впорядковувати шари.

**Залежить від:** 10
**Оцінка:** 1,5 тижня

## Задачі

### Палітра і додавання
- [ ] Палітра: прямокутник, коло, лінія, текст, число, смуга прогресу, дуга, картинка, графік (без «Індикатора»).
- [ ] Додавання кліком (у центр) або перетягуванням на точку полотна; id `<тип>_<N>`.

### Полотно
- [ ] Переміщення мишею з прив'язкою до сітки 4 px; стрілки — 1 px, Shift — 10 px.
- [ ] 8 маркерів зміни розміру; мінімум 4 px (лінія — 0 по висоті); тонкі елементи мають збільшену зону захоплення.
- [ ] Видалення: кнопка «Видалити» у властивостях і клавіша Delete.

### Властивості (базові)
- [ ] id, тип (випадаючий список; зміна типу підставляє розміри й знімає несумісну прив'язку з повідомленням),
      x/y/w/h, колір, параметр-джерело даних, формат, **шрифт** (Literata — за замовчуванням / JetBrains Mono / Press Start 2P, + «застосувати до всіх») і **розмір 8–72 px** (текст, число, смуга, дуга; графік — лише шрифт).
- [ ] У властивостях — лише статичні значення; усе, що залежить від параметрів, — у блоці «Умови» (етап 13).

### Шари
- [ ] Порядок у блоці «Шари» = порядок накладання; **верхній рядок — над усіма**; номер рівня біля рядка.
- [ ] Зміна порядку: перетягування рядка (синя лінія вставки), кнопки ↑/↓ у рядку,
      ↑/↓ коли фокус у блоці, Ctrl/⌘+↑/↓ з будь-якого місця.
- [ ] Клік по рядку — вибір елемента; у рядку — тип, параметр, ↻ кут, ◐ прозорість, ⇄ позиція, кількість умов.

### Права колонка
- [ ] Блок «Картинка»: «+ Файл…» приймає картинки, GIF і відео; для анімацій — перемикач «Цикл / Один раз», «Програти з початку», «Кадр, мс»; анімація грає в прев'ю.
- [ ] Блоки «Властивості», «Вигляд», «Картинка», «Графік», «Умови», «Параметри екрана», «Параметри в коді»
      згортаються кліком по заголовку (▾); стан згортання запам'ятовується між сеансами.

### Undo/redo
- [ ] Усі зміни — через `QUndoCommand`; перетягування й ресайз — одна команда на жест.

## Критерії готовності
- [ ] Сторінку з макета можна зібрати мишею за кілька хвилин.
- [ ] Перетягування й ресайз працюють і в масштабі 50 %, і в 400 %.

## Тести
- pytest-qt: додавання, рух, ресайз, Delete, зміна типу, зміна порядку шарів трьома способами, undo/redo.
