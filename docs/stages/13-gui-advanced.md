# Етап 13 — GUI: розширені властивості

**Мета:** налаштування логіки й трансформацій у панелі властивостей і на полотні.

**Залежить від:** 12; генераторні частини — 04, 05, 06, 08
**Оцінка:** 1,5 тижня

**Принцип:** у властивостях — лише статичні значення. **Усе, що залежить від параметрів, налаштовується в блоці «Умови».**

Порядок блоків правої колонки (кожен згортається кліком по заголовку, стан запам'ятовується):
Властивості → Вигляд → Картинка / Графік (за типом) → Умови → Параметри екрана → Параметри в коді.

## Вигляд (статичні значення)
- [ ] Непрозорість 0–100 % (поле + повзунок) і «Застосувати непрозорість до всіх елементів сторінки».
- [ ] Кут ° (поле + повзунок −180…180) — не для графіка.
- [ ] Точка повороту — константа: пресети або власні x/y; перетягування червоного хрестика на полотні.
- [ ] Підказка, які властивості зараз змінюються умовами.

## Умови
Два види записів, кнопки «+ Умова» і «+ Залежність»:
- [ ] **Умова:** «якщо `<параметр> <оператор> <значення>` → `<властивість>` = `<значення>`»;
      властивості: колір, текст/формат, видимість, непрозорість %, кут °, x, y.
      Умова, що зараз спрацьовує, підсвічена.
- [ ] **Залежність:** «від `<числовий параметр>` → `<властивість>`: при мін `a`, при макс `b`»;
      властивості: непрозорість %, кут °, x, y. Вибір властивості підставляє розумні `a`/`b`.
- [ ] Перевірки: числа, непрозорість 0–100, повідомлення біля блоку.
- [ ] **Блокування статичних полів:** якщо на властивість є хоч одна умова чи залежність, відповідне поле у
      «Властивостях» / «Вигляді» вимикається (колір → «Колір», текст → «Формат», непрозорість → поле й повзунок,
      кут → поле й повзунок, x/y → поля x/y) з підказкою, які параметри ним керують; після видалення останньої
      такої умови поле знову активне. Видимість окремого статичного поля не має.
- [ ] Для залежностей x/y на полотні — жовті пунктирні рамки «мін»/«макс»; перетягування елемента чи стрілки
      зсувають базову позицію і всі значення x/y в умовах і залежностях разом.
- [ ] Рамка, маркери й ресайз — у повернутій системі координат (з урахуванням кута з умов).
- [ ] Перетягування bool-параметра на елемент додає умову «якщо … = false → сховати».
- [ ] Схований умовою елемент у прев'ю не малюється (як на платі); на активній сторінці лишається лише тонка
      пунктирна рамка, щоб його можна було знайти й вибрати; на неактивних сторінках не видно нічого.

## Картинка
- [ ] Статичний файл (параметр не прив'язано): список «Файл» з усіма картинками бібліотеки проєкту + «+ Файл…» для нової;
      вписування, «розмір як у картинки», підказка шляху й обсягу.
- [ ] Зі шляху в `str`-параметрі: список «Картинки на платі (/img)» (завантаження кількох, ×); **клік по картинці**
      ставить її шлях тестовим значенням параметра й показує в прев'ю; поточна підсвічена; підказка, що на платі
      шлях передає код розробника.

## Графік
- [ ] Підписи осей X/Y, Y мін/макс (порожньо = авто, мін < макс), вигляд, сітка.

## Критерії готовності
- [ ] Усі налаштування з `docs/plan.html` доступні й дають той самий код, що й генератор з етапів 04–08.
- [ ] Проєкт старого формату (з `show`, «прозорістю/позицією/кутом з параметра») відкривається з автоматичною міграцією в «Умови».

## Тести
- pytest-qt для кожного блоку; перетягування точки повороту; поведінка рамок позиції; згортання блоків.
