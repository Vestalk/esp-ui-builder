# Етап 06 — Графік і параметр `series`

**Мета:** елемент «Графік», що приймає список мап `{x: y}` і малює лінію або стовпці з підписаними осями.

**Залежить від:** 03 (для підписів кирилицею — 07)
**Оцінка:** 4–5 днів

## Параметр `series`
- Значення — список мап: `[{0: 14}, {3: 13}, {6: 15}]`; у кожній мапі ключ — X, значення — Y.
- Налаштування: макс. точок (2–256), тип ключа X — число або мітка до 7 символів (`'Пн'`, `'12:00'`), межі Y.
- Числові X сортуються за зростанням; мітки — у порядку списку.
- Ключі X у списку унікальні; у мапі може бути кілька пар — вони розгортаються в окремі точки.

## Елемент «Графік»
| Властивість | Значення |
|---|---|
| Підпис осі X / Y | рядок до 16 символів; Y — над віссю зліва, X — під віссю справа |
| Y мін / макс | число або «авто» (з меж параметра, розширених до даних) |
| Вигляд | лінія / лінія з точками / стовпці |
| Сітка | 3 горизонтальні лінії (мін, середина, макс) |
| Мітки | Y: мін і макс; X: перша, середня (якщо ширина > 110 px), остання |

Поворот для графіка не підтримується. Непрозорість і позиція — так: статично у властивостях, від параметрів — через «Умови».

## Критерії готовності
- [ ] Графік температури за добу оновлюється на платі при додаванні точки; швидкість ≤ 40 мс для 24 точок.
- [ ] Ручні межі Y обрізають значення поза діапазоном; «авто» розширює.
- [ ] Порожній список → напис «немає даних».
