# Етап 15 — Пакування, документація, приклади

**Мета:** програма, яку можна встановити й почати користуватися без розробника.

**Залежить від:** усі попередні
**Оцінка:** 4–5 днів

## Задачі
- [ ] PyInstaller-збірки для Windows, macOS, Linux у CI; підпис і нотаризація macOS за потреби.
- [ ] Вбудовані ресурси: шрифт за замовчуванням, профіль дисплея, шаблони, runtime.
- [ ] Калькулятор пам'яті в рядку стану (флеш: код + шрифти + картинки; RAM: найбільший буфер області).
- [ ] Документація `docs/user-guide.md`: швидкий старт (від підключення дисплея до першого екрана на платі),
      параметри, логіка, трансформації, сторінки, генерація, MicroPico і `mpremote`.
- [ ] Приклади в `examples/`: метеостанція (з макета), дашборд датчиків зі стрілкою, дві сторінки з налаштуваннями.
- [ ] Чек-лист ручної перевірки на платі для кожного релізу.

## Критерії готовності
- [ ] Новий користувач за інструкцією отримує свій екран на платі менш ніж за 30 хвилин.
- [ ] Усі приклади генеруються й працюють на платі.
