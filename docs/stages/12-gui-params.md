# Етап 12 — GUI: параметри і живе прев'ю

**Мета:** створювати параметри сторінки, прив'язувати їх до елементів і бачити результат на тестових значеннях.

**Залежить від:** 11
**Оцінка:** 1 тиждень

## Задачі

### Параметри
- [ ] Панель «Параметри екрана»: список з типом і межами, × для видалення (прибирає всі посилання).
- [ ] **Редагування параметра** (✎ у рядку або подвійний клік): той самий діалог, заповнений поточними значеннями,
      кнопка «Зберегти зміни». Можна змінити назву, тип, межі, варіанти, макс. довжину/точок, значення за замовчуванням.
  - Перейменування оновлює всі посилання: прив'язку елементів, умови й залежності, тестове значення.
  - Зміна меж обмежує поточне тестове значення новим діапазоном; зміна варіантів enum замінює недійсні значення в умовах.
  - Зміна типу: несумісні прив'язки знімаються, залежності від нечислового параметра видаляються,
    умови скидаються до оператора й значення за замовчуванням; підсумок показується повідомленням.
  - Перевірка унікальності назви не враховує сам параметр, що редагується.
- [ ] Діалог «Новий параметр»: назва, тип (float, int, bool, str, enum, series), поля за типом, значення за замовчуванням;
      валідація з `core` з повідомленням біля поля.
- [ ] Перетягування параметра:
  - на сумісний елемент — прив'язка;
  - `bool` на будь-який елемент — додає умову «якщо … = false → сховати» у блок «Умови»;
  - на вільне місце — новий елемент відповідного типу (число, текст, графік для series).
- [ ] Поле «Параметр» у властивостях показує лише сумісні параметри.

### Тестові значення
- [ ] Для кожного параметра — повзунок (float/int), прапорець (bool), список (enum), поле з підказками шляхів (str),
      поле `x:y; x:y` з перевіркою і кнопкою «↻ випадкові» (series).
- [ ] Прев'ю оновлюється одразу, через `core.evaluate`.

### Перевірки
- [ ] Рядок стану: елементи за межами екрана, невикористані параметри, картинки без файлу.
- [ ] Блок «Параметри в коді» показує `DEFAULTS` для поточної сторінки.

## Критерії готовності
- [ ] Прив'язка й тестові значення поводяться як у `docs/plan.html`.
- [ ] Прев'ю збігається з кадром з unix-порту MicroPython для прикладу (етап 03).

## Тести
- pytest-qt: створення кожного типу параметра, помилки валідації, три сценарії перетягування, видалення параметра.
