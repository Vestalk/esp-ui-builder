# Етап 07 — Шрифти з кирилицею

**Мета:** український текст будь-якого розміру на дисплеї; лише потрібні гліфи, щоб економити флеш і RAM.

**Залежить від:** 03
**Оцінка:** 4–5 днів

## Вибір шрифту
- У властивостях тексту, числа, смуги, дуги й графіка є список «Шрифт» і кнопка «Застосувати шрифт до всіх елементів сторінки».
- Поки що три вбудовані шрифти (усі SIL OFL 1.1, ліцензії кладуться в `assets/fonts/`):
  - **Literata** — з засічками, `serif`, **за замовчуванням**;
  - **JetBrains Mono** — моноширинний, `mono`;
  - **Press Start 2P** — піксельний, `pixel`; найчіткіший при розмірах, кратних 8 (8, 16, 24 px); підказок у GUI немає.
- Усі три шрифти перевірено: є всі українські літери (Є І Ї Ґ є і ї ґ), апостроф ʼ і знак °.
- Шрифт — статична властивість елемента, не від параметра. У `ui_fonts.py` потрапляють лише використані пари «шрифт + розмір».
- Прев'ю в GUI малює тими самими шрифтами (у макеті вони вбудовані в сторінку).

## Розмір шрифту
- Задається у властивостях елемента («Шрифт, px», 8–72) для тексту, числа, смуги й дуги; статичний, не від параметра.
- Кожен використаний розмір — окремий набір гліфів, підготовлений на комп'ютері під час генерації; на платі не масштабується.
- Текст малює `ui_fonts.draw_text()` у буфер `framebuf`, драйвер лише передає готовий буфер через `Display.blit()` —
  тому результат не залежить від вибраного драйвера; власні шрифти драйверів не використовуються.

## Задачі
- [ ] `assets/fonts.py`: TTF → 1-бітні bitmap-гліфи (`freetype-py`) для заданих розмірів.
- [ ] Збір набору символів з проєкту: статичні тексти, формати, варіанти `enum`, підписи осей, тексти з умов;
      плюс цифри, `.,-+%°:` і латиниця для чисел. Для `str`-параметрів — налаштовуваний діапазон
      (за замовчуванням: латиниця + українська кирилиця).
- [ ] Генерація `ui_fonts.py`: дані гліфів (`bytes`), ширини, `draw_text(fb, text, x, y, size, color)`
      через `framebuf.blit` з палітрою.
- [ ] Три вбудовані шрифти: `serif` (Literata, за замовчуванням), `mono` (JetBrains Mono) і `pixel` (Press Start 2P); для `pixel` — растеризація без згладжування точно по сітці 8 px.
- [ ] `draw_text(fb, text, x, y, font, size, color)`; набори гліфів — окремо для кожної пари «шрифт + розмір».
- [ ] Пізніше: додавання власного TTF у бібліотеку шрифтів проєкту.
- [ ] Вирівнювання ліво/центр/право, обрізання тексту за шириною елемента з «…».
- [ ] Заміна символу, якого немає у шрифті, на «?» + попередження в генераторі.

## Критерії готовності
- [ ] «Погода · Київ», «ПЕРЕГРІВ», «Вологість 40 %» відображаються на платі без пропусків.
- [ ] Розмір `ui_fonts.py` для прикладу ≤ 40 КБ.
- [ ] Прев'ю в GUI використовує ті самі bitmap-гліфи (вигляд 1:1).
- [ ] Текст розмірів 8, 12, 16, 24, 40 px виглядає однаково з обома драйверами (`ui_st7789`, `st7789py`) на платі.
- [ ] Генератор показує обсяг `ui_fonts.py` за шрифтами й розмірами (напр. «Literata 12/40 px · JetBrains Mono 14 px · Press Start 2P 16 px»).
- [ ] Press Start 2P 16 px на платі без розмитих чи «подвоєних» пікселів.

## Тести
- Набір символів для прикладу збирається правильно (включно з умовами й enum).
- Еталонні кадри тексту різних розмірів.
