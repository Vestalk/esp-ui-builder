# Етап 05 — Прозорість, позиція, поворот і залежності

**Мета:** три трансформації елементів, що однаково виглядають у прев'ю і на платі.
**Принцип:** у властивостях — лише базові значення (непрозорість %, кут °, точка повороту).
Зміна від параметрів — лише записами в «Умовах»: умовами (етап 04) або залежностями `mapping` (цей етап).

**Залежить від:** 03 (бажано після 04)
**Оцінка:** 1 тиждень

## Залежність (`mapping`) — новий вид запису в «Умовах»
- «від `<числовий параметр>` змінювати `<властивість>`: при мін → `a`, при макс → `b`» (лінійно, з обмеженням).
- Властивості: непрозорість %, кут ° (не для графіка), x, y.
- Код: `angle = -90 + (180) * (p['humidity'] - 0) / 100`.

## Прозорість
- Базова непрозорість 0–100 % у властивостях («Вигляд»), кнопка «Застосувати до всіх елементів сторінки».
- Від параметрів: умова (наприклад, `alarm = false → 30 %`) або залежність.
- Доступна для всіх елементів.
- На платі: альфа-змішування кольору елемента з тим, що вже намальовано в буфері області
  (тому перекриття з етапу 03 обов'язкове). Для 0 % елемент не малюється.
- Код: `alpha = 0.6` або `alpha = 1.0 if p['alarm'] else 0.3`, або лінійна формула.

## Позиція
- Базові x, y — у властивостях; від параметрів — залежності `x`/`y` або умови `x`/`y`.
- Код: `x = 184 + (100) * (p['humidity'] - 0) / 100`.
- При зміні позиції: очистити стару область (з перемальовкою того, що під нею), намалювати в новій.

## Поворот
- Базовий кут — у властивостях; від параметрів — залежність або умова `кут`.
- **Точка повороту — константа проєкту**, не параметр: пресет (центр, кути, середини сторін) або x/y від
  лівого верхнього кута елемента. Рухається разом з елементом, якщо позиція задана параметром.
- **Не застосовується до графіка.**
- Реалізація (`framebuf` не вміє повертати):
  - прямокутник, лінія, смуга, дуга — перетворенням вершин (`framebuf.poly`, `line`);
  - коло — без змін, крім випадку точки повороту не в центрі (зсув центру);
  - статично повернуті текст і картинки — повернутий bitmap рахується на генерації;
  - динамічно повернуті текст і картинки — попіксельно під час роботи; обмеження розміру з етапу 01
    (попередження в генераторі, якщо елемент більший).
- Область очищення = описаний прямокутник повернутого елемента.
- Код: `angle = …`, `PIVOT = (x, y)`, виклик малювання з `angle=angle, pivot=PIVOT`.
- Порядок у коді: базові значення → залежності → умови → `PIVOT` → малювання.

## Критерії готовності
- [ ] Стрілка-лінія з `humidity 0…100 → −90°…90°` навколо лівого кінця працює на платі без слідів.
- [ ] Напівпрозорий прямокутник над текстом дає змішаний колір, як у прев'ю.
- [ ] Елемент з X від параметра їздить між крайніми положеннями без артефактів.
- [ ] Генератор попереджає про динамічний поворот великих текстів/картинок.

## Тести
- `core.evaluate`: кут, точка повороту, позиція, альфа для таблиці значень.
- Запуск на unix-порті: порівняння кадрів з еталоном для 0°, 45°, 90°, прозорості 0/50/100 %.
