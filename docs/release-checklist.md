# Чек-лист релізу (ручна перевірка на платі)

Автоматичні тести (`pytest`) перевіряють код на CPython і на unix-порті MicroPython, а кадри — проти
прев'ю. Те, що бачить лише людина з платою в руках, — тут. Відмічайте кожен пункт для кожного релізу;
результати й заміри — у нотатках до релізу.

Плата: ________ · PSRAM: так / ні · Прошивка MicroPython: ________ · Дата: ________

## 1. Збірки
- [ ] CI зелений на `main` (lint, mypy, тести на Linux/macOS/Windows, MicroPython unix-порт).
- [ ] `__version__` у `src/espui/__init__.py` оновлено, тег `vX.Y.Z` створено → workflow «Release» зібрав
      артефакти для Windows, macOS і Linux.
- [ ] Кожна збірка запускається на чистій машині (без Python): `ESP UI Builder` відкриває вікно;
      той самий файл з аргументами працює як CLI: `espui generate examples/weather.espui -o out` пише файли
      (macOS: `ESP UI Builder.app/Contents/MacOS/espui generate …`).
- [ ] macOS: програма відкривається без попередження Gatekeeper (якщо підписано й нотаризовано).

## 2. Новий користувач (≤ 30 хв)
- [ ] Людина, що не бачила програму, проходить «Швидкий старт» з [`user-guide.md`](user-guide.md)
      від підключення дисплея до свого екрана на платі. Час: ____ хв.

## 3. Приклади на платі
Для кожного: генерація в порожню папку → MicroPico «Upload project» на **чисту** плату → Run `main.py`.

| Приклад | Що перевірити | ✓ |
|---|---|---|
| `weather.espui` | текст українською, °C, смуга, дуга; `ui.set_alarm(True)` → «ПЕРЕГРІВ», температура червона | |
| `sensors.espui` | стрілка йде за температурою без слідів; CO₂ > 1500 → червоний і «Провітріть»; графік | |
| `pages.espui` | сторінки перемикаються кожні 5 с, щоразу повна перемальовка | |
| `transforms.espui` | напівпрозорий прямокутник над текстом; нахилені елементи; маркер їздить від краю до краю | |
| `chart.espui` | лінія, точки, стовпці; «немає даних»; нова точка додається | |
| `images.espui` | іконка змінюється (sun/cloud/rain); спінер крутиться рівно; «один раз» зупиняється | |

## 4. Заміри (`main.py` друкує час `update()`)
| Що | Мета | Факт |
|---|---|---|
| `update()` однієї цифри (weather) | ≤ 25 мс | |
| Графік 24 точки, нова точка (chart) | ≤ 40 мс | |
| Картинка 120×60 (images) | ≤ 30 мс | |
| Анімація 64×64, 80 мс/кадр | рівно, без пауз | |
| Вільна RAM після `draw()` (`gc.mem_free()`) | > 30 КБ без PSRAM | |

## 5. Драйвери й орієнтації
- [ ] `weather.espui` з драйвером `st7789py` (Дисплей → Драйвер) виглядає так само, як з `ui_st7789`.
- [ ] Орієнтації 0, 1, 2, 3: зображення не дзеркальне, кольори правильні.
- [ ] 40 і 80 МГц без артефактів (80 — на пінах IOMUX).

## 6. Програма
- [ ] Закрити програму з незбереженим новим проєктом → запустити знову → запропоновано відновлення.
- [ ] Змінити `main.py` у згенерованій папці → згенерувати знову → `main.py` не змінено, є `main.example.py`.
- [ ] Відкрити експорт з макета (`docs/plan.html` → Файл → Експорт) → імпорт працює.
- [ ] Оцінка пам'яті в рядку стану близька до розміру папки на диску.
