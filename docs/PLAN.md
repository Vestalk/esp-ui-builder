# ESP32-S3 UI Builder — план розробки (огляд)

Десктопна програма на Python для візуального конструювання інтерфейсу дисплея під ESP32-S3.
Результат — **лише Python-код**: модулі MicroPython (`.py`), які завантажуються на плату через **MicroPico** (VS Code)
і містять клас `UI` з методами відображення: вони приймають параметри й виводять їх у визначених місцях екрана.

- Макет інтерфейсу програми: [`plan.html`](plan.html) — інтерактивний, відкривається в браузері.
- Детальні етапи реалізації: [`stages/`](stages/) — кожен файл можна брати в роботу окремо.

---

## Обсяг першої версії

- **Дисплей:** лише **2.0" TFT SPI GMT020-02-8B ver 1.21** — ST7789, 240×320, 4-wire SPI, RGB565.
  Профілі дисплеїв закладаються в архітектуру, щоб інші додати пізніше без переробки.
- **Плата і середовище:** чип вибирається (ESP32-S3 — основний, також ESP32 і ESP32-C3), MicroPython, MicroPico.
  Усе, що генерується, — Python: драйвери дисплея лише на Python, без модулів на C і без власних збірок прошивки.
  Потрібен тільки стандартний MicroPython; згенерований код використовує `machine` і `framebuf`.
- **Програма:** кілька сторінок, полотно з усіма сторінками й масштабом, елементи (прямокутник, коло, лінія,
  текст, число, смуга, дуга, картинка з GIF/відео-анімацією, графік), вибір шрифту, шари, параметри з тестовими значеннями, прозорість, поворот з постійною
  точкою, збереження сеансу, генерація.
- **Принцип налаштування:** у властивостях елемента — лише статичні значення; **усе, що залежить від параметрів**
  (видимість, колір, текст, непрозорість, кут, позиція), задається в блоці «Умови» — умовами «якщо … то …»
  і плавними залежностями «від параметра: мін → макс». Блоки правої колонки згортаються.
- **Поза першою версією:** тач, інші дисплеї, плавні анімації переходів між станами, прошивка й завантаження прямо з програми.
  Перемикання сторінок на пристрої реалізує розробник прошивки.

## Ключові рішення

| Питання | Рішення |
|---|---|
| GUI | PySide6 (Qt 6), `QGraphicsScene/View`, `QUndoStack` |
| Модель даних | pydantic v2, JSON-файл проєкту `.espui` |
| Генерація | Jinja2-шаблони → `.py` для MicroPython |
| Драйвер дисплея | **Вибирається в налаштуваннях дисплея, лише Python-драйвери**: вбудований `ui_st7789.py` (за замовчуванням) або `st7789py_mpy`; файл драйвера завжди лежить у папці генерації; сторінки працюють з будь-яким через адаптер `Display` |
| Малювання на платі | `framebuf.FrameBuffer` (RGB565) на область елемента → запис у дисплей одним блоком |
| Обчислення властивостей | Один модуль `core/evaluate.py` для прев'ю в GUI і для тестів генератора: однакові формули |
| Шрифти | Вибір шрифту: Literata (з засічками, за замовчуванням), JetBrains Mono (моно) або Press Start 2P (піксельний), усі OFL з повною українською; TTF → bitmap (`freetype-py`), лише використані гліфи |
| Картинки | Оригінали вбудовані в `.espui`; при генерації автоматично Pillow → RGB565 `img/*.bin` поруч з кодом; `.vscode/settings.json` для MicroPico, щоб `.bin` завантажувались разом з `.py`; на платі читання по рядках. GIF і відео → кадри в окремій папці `img/<назва>/`, відтворення циклічно або один раз через неблокуючий `ui.tick()` |
| Тести | pytest; згенерований код запускається на unix-порті MicroPython з фейковим дисплеєм; ручна перевірка на платі |

## Структура репозиторію

```
esp-ui-builder/
├── docs/                  # план, етапи, макет
├── pyproject.toml
├── src/espui/
│   ├── core/              # моделі, валідація, .espui, evaluate.py, кольори
│   ├── displays/          # профіль GMT020-02-8B (YAML)
│   ├── assets/            # шрифти, картинки
│   ├── generators/micropython/   # generator.py + templates/*.py.j2 + runtime/ (драйвер, хелпери)
│   ├── gui/               # вікно, полотно, панелі, діалоги, команди undo
│   └── cli.py             # espui generate project.espui -o out/
├── tests/{unit,mpy,gui}/
└── examples/
```

## Дорожня карта

Етапи впорядковані так, щоб найризиковіше (швидкість і пам'ять MicroPython на реальній платі) перевірялось першим,
а кожен етап давав результат, який можна запустити або перевірити тестами.

| # | Етап | Залежить від | Оцінка | Результат |
|---|---|---|---|---|
| 00 | [Підготовка середовища і заліза](stages/00-setup.md) | — | 2–3 дні | Репозиторій, CI, плата з MicroPython, дисплей світиться |
| 01 | [Драйвер ST7789 і заміри](stages/01-driver.md) | 00 | 3–4 дні | `ui_st7789.py`, цифри швидкості й пам'яті |
| 02 | [Модель даних і формат `.espui`](stages/02-model.md) | 00 | 1 тиждень | Моделі, валідація, збереження/відкриття, `evaluate.py` |
| 03 | [Генератор: базові елементи, `draw`/`update`, CLI](stages/03-generator-basic.md) | 01, 02 | 1,5 тижня | `espui generate` дає робочий екран на платі |
| 04 | [Умови: дискретні зміни від параметрів](stages/04-logic.md) | 03 | 3–4 дні | Умови «якщо … то …» у коді та прев'ю |
| 05 | [Прозорість, позиція, поворот і залежності](stages/05-transforms.md) | 03 | 1 тиждень | Залежності від параметрів; трансформації однакові в прев'ю та на платі |
| 06 | [Графік і параметр `series`](stages/06-chart.md) | 03 | 4–5 днів | Графік зі списку мап `{x: y}` з підписами осей |
| 07 | [Шрифти з кирилицею](stages/07-fonts.md) | 03 | 4–5 днів | `ui_fonts.py`, український текст на екрані |
| 08 | [Картинки](stages/08-images.md) | 03 | 4–5 днів | Статичні й зі шляху в параметрі, GIF/відео-анімації, `.bin` на флеші |

| 10 | [GUI: каркас, дисплей, сторінки, робоча зона](stages/10-gui-shell.md) | 02 | 1 тиждень | Вікно, вкладки сторінок, полотно з масштабом |

| 13 | [GUI: розширені властивості](stages/13-gui-advanced.md) | 12, 04–08 | 1,5 тижня | Логіка, прозорість, позиція, поворот, графік, картинки |

Етапи 04–09 між собою незалежні, як і 10 від 03, тож їх можна вести паралельно.

## Ризики

| Ризик | Що робимо | Де |
|---|---|---|
| Швидкість MicroPython при малюванні | Часткове оновлення, `framebuf`, `@micropython.viper`, SPI 40–80 МГц | 01, 03 |
| Пам'ять на буфери областей | Буфер лише на область елемента, великі — смугами, PSRAM | 01, 03 |
| Порядок байтів RGB565 | Кольори одразу в порядку дисплея; перевірка на залізі | 01 |
| Прозорість і перекриття | Перемальовка області разом з усіма елементами під нею в порядку шарів | 03, 05 |
| Динамічний поворот тексту й картинок повільний | Обмеження розміру; статичний поворот рахується на генерації | 05 |
| Кирилиця | Власний конвертер, лише використані гліфи; усі три шрифти перевірено на всі українські літери | 07 |
| Анімації займають багато флешу | ≤ 48 кадрів, кадри під розмір елемента, попередження про обсяг | 08 |
| ESP32-S3 у MicroPico — експериментальна підтримка | Запасний шлях — `mpremote` | 00 |
| Модуль без піна BLK | BLK необов'язковий | 00, 03 |
| Сторонній драйвер змінить API | Адаптер `Display` у `ui_display.py`; файл `st7789py.py` фіксованої версії постачається з програмою | 01, 03 |
