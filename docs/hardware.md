## Перевірка

1. Прошити плату:
   ```sh
   pip install esptool
   esptool.py --chip esp32s3 --port <PORT> erase_flash
   esptool.py --chip esp32s3 --port <PORT> write_flash -z 0 ESP32_GENERIC_S3-<версія>.bin
   ```
   Прошивка: <https://micropython.org/download/ESP32_GENERIC_S3/>.
2. VS Code → MicroPico: **Configure Project**, **Switch Stubs → ESP32**.
3. Відкрити `tools/hw_smoke.py` → **Run current file on Pico**, або `mpremote run tools/hw_smoke.py`.
4. Очікувано: червоний → зелений → синій → чорний, без смуг і зсувів; у REPL час заливки кожного кольору.

## Інші дисплеї

Підключення таке саме, як у GMT020-02-8B: SPI (SCL/SCK → GPIO 12, SDA/MOSI → GPIO 11), CS → 10,
DC → 9, RES/RST → 8, підсвітка → 7, живлення 3V3. Інші піни можна вибрати в діалозі «Дисплей».

| Дисплей | Підписи на модулі | Примітки |
|---|---|---|
| 3.5" IPS 480×320 ILI9488 | VCC, GND, CS, RESET, DC/RS, SDI(MOSI), SCK, LED, SDO(MISO) | `LED` — підсвітка (на 7 або одразу на 3V3); `SDO` не потрібен; піни `T_*` (сенсор) і `SD_*` (картка) не використовуються. Модулі з живленням 5 V мають стабілізатор — дивіться перемичку J1. Колір через SPI лише 18-біт: кадр утричі «важчий», ніж у 16-біт, тож тримайте 40 МГц і короткі дроти. |
| 1.28" круглий GC9A01 | VCC, GND, SCL, SDA, DC, CS, RST, BL | `BL` — підсвітка. |

Не перевірено на платі: послідовності ініціалізації ILI9488 / ILI9341 / GC9A01 взято з поширених
відкритих драйверів; якщо кольори «негативні» — перемкніть «Інверсія кольорів», якщо червоний і синій
переплутані — порядок кольорів у «Свій розмір…».


## Сенсорний екран і SD-карта модуля

Вмикаються окремо в діалозі «Дисплей» (за замовчуванням вимкнені). Обидва XPT2046 і SD-карта сидять
на шині SPI дисплея, тож потрібен ще один пін — **MISO** (запропоновано GPIO 13):

| Модуль | Куди | Типово (ESP32-S3) |
|---|---|---|
| `T_CLK`, `SD_SCK` | SCL дисплея | GPIO 12 |
| `T_DIN`, `SD_MOSI` | SDA дисплея | GPIO 11 |
| `T_DO`, `SD_MISO` (і `SDO` дисплея, якщо хочете) | MISO | GPIO 13 |
| `T_CS` | окремий пін | GPIO 14 |
| `T_IRQ` (не обов'язково) | окремий пін | GPIO 15 |
| `SD_CS` | окремий пін | GPIO 21 |
| CST816S: `SDA`, `SCL`, `INT`, `RST` | I2C, окремі піни | 16, 17, 18, — |

Модулі без CS (7 пінів, CS з'єднаний з GND на платі) і без RES теж підходять: залиште ці поля
порожніми. Не перевірено на платі: драйвери сенсорів і SD-карти перевірені на емуляторах.
