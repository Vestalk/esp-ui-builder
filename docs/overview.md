# ESP UI Builder — документація

Десктопна програма (Windows, macOS, Linux), у якій екран для дисплея ESP32 збирається мишею, а на
виході — готовий код **MicroPython** для плати. Компілювати нічого не треба: стандартна прошивка
MicroPython, файли заливаються на плату як є (MicroPico у VS Code або `mpremote`).

[Макет інтерфейсу](https://vestalk.github.io/esp-ui-builder/plan.html) — початковий задум програми.

## Можливості

- **Елементи:** прямокутник, коло, лінія, текст, число, смуга прогресу, дуга, картинка (і анімація
  з GIF), графік. Шари, непрозорість, поворот навколо будь-якої точки.
- **Параметри** — значення, які змінює ваш код на платі (температура, стан, підпис…).
- **Умови й залежності:** «якщо `t > 30` / `t` у діапазоні 18…25 → колір / текст / видимість /
  непрозорість / кут / x / y» і плавні залежності (кут стрілки від значення).
  **Тестові значення** показують результат одразу в програмі.
- **Кілька сторінок** в одному проєкті.
- **Шрифти з українською абеткою** (Literata, JetBrains Mono, Press Start 2P, 8–72 px): на плату йдуть
  лише потрібні символи потрібних розмірів.
- **Смуга прогресу і дуга:** колір заповнення й доріжки, показ доріжки й числа вмикаються окремо.
- **Швидкість на платі:** перемальовується лише змінене; **Дисплей → Пам'ять** — буфер області й
  кеш картинок під вашу плату (з PSRAM зміни з'являються одразу, без смуг).
- **Перевірки до генерації:** помилки проєкту, зайняті й повторені піни, оцінка флешу й RAM.
- **Кілька елементів одразу:** Shift+клік, рамка мишею по порожньому місцю сторінки (з Shift —
  додати), Shift / Ctrl(⌘)+клік у «Шарах»; разом — перетягування, стрілки, видалення,
  копіювання, колір і непрозорість.
- **👁 і 🔒 у «Шарах»:** сховати елемент у редакторі (щоб дістатися до того, що під ним) і
  заблокувати (на полотні не вибирається й не рухається — напр. фон). Лише для редактора: на
  платі сторінка та сама. Також «Правка» → Ctrl+Shift+H / Ctrl+Shift+L, «Показати й
  розблокувати все».
- **Розташування:** вирівняти (ліво, центр, право, верх, середина, низ) і розподілити з рівними
  проміжками; кілька елементів — відносно виділення, один — відносно екрана.
- **Копіювати / вставити / дублювати** елемент (Ctrl+C / Ctrl+V / Ctrl+D на полотні чи в «Шарах»,
  меню «Правка») — і на іншу сторінку: потрібні параметри копіюються разом з елементом.
- Автозбереження, скасування / повтор, відновлення після збою.

**ESP32 CYD** — плата з уже вбудованим дисплеєм: виберіть профіль CYD, і програма сама

Калібрування сенсора під свою плату — у «Дисплей → Сенсорний екран».
профілі. Для них сенсор XPT2046 пропонується одразу; його можна вимкнути.

Плати: **ESP32-S3** (рекомендована), ESP32, ESP32-C3. За бажанням — **сенсорний екран** XPT2046
(SPI) або CST816S (I2C).

## Підключення (ESP32-S3, типово)

| Дисплей | GPIO | | Сенсор | GPIO |
|---|---|---|---|---|
| VCC / GND | 3V3 / GND | | MISO (T_DO) | 13 |
| SCL (SCK) | 12 | | T_CS / T_IRQ (XPT2046) | 14 / 15 |
| DC | 9 | | CST816S SDA / SCL / INT | 16 / 17 / 18 |
| CS | 10 (можна без) | | | |
| RES | 8 (можна без) | | | |
| BLK | 7 (можна без) | | | |

T_CLK і T_DIN — на ті самі GPIO, що SCL і SDA дисплея (спільна шина). Уникайте
GPIO 19–20 (USB), 26–37 (флеш і PSRAM), 0, 3, 45, 46 (режим старту). Інші піни вибираються в
діалозі **Дисплей…** — він підкаже, якщо пін зайнятий.

## Як почати

1. **Встановлення** (Python ≥ 3.11):
   ```sh
   python3 -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
   pip install -e .
   espui gui                                            # або: python -m espui gui
   ```
2. **Прошивка плати** — MicroPython для вашого чипа з
   [micropython.org/download](https://micropython.org/download/) (для ESP32-S3 з PSRAM — варіант
   `SPIRAM_OCT`):
   ```sh
   esptool.py --chip esp32s3 --port <ПОРТ> erase_flash
   esptool.py --chip esp32s3 --port <ПОРТ> write_flash -z 0 <прошивка>.bin
   ```
3. **Екран:** **Дисплей…** → модель, піни, пам'ять; накидайте елементи; додайте параметри й умови.
4. **▶ Згенерувати** → виберіть папку: програма перепитає, куди саме запише файли
   (і чи замінить наявні), — у ній з'явиться тека з назвою сторінки.
5. **На плату:** залийте теку (MicroPico — «Upload project», або `mpremote cp -r <тека> :`) і
   підключіть сторінку у своєму `main.py`.

## Код на платі

```python
from ui.main import ui_display, ui_main   # тека сторінки на платі: /ui/main

display = ui_display.create()
ui = ui_main.UI(display)
p = dict(ui_main.DEFAULTS)                # усі параметри зі значеннями за замовчуванням
ui.draw(p)                                # повна перемальовка

while True:
    p["temperature"] = read_sensor()      # ваш код
    ui.update(p)                          # перемальовує лише змінене
    ui.tick()                             # анімації картинок (якщо є)
```

Сенсор (якщо ввімкнений у **Дисплей…**):

```python
touch = ui_display.create_touch(display)
point = touch.read()                      # (x, y) на екрані або None
```

### Натискання на елементи

У редакторі для кнопки задається лише **назва процедури** — поле **«При натиску»**, напр.
`start_pump`. Самі процедури — у коді проєкту: мапа «назва → функція» передається у
`draw()`, і сенсор слухає у фоні — без циклу:

```python
from ui.main import ui_display, ui_main

def start_pump():                         # викликається один раз на кожне натискання
    p["status"] = "Працює"

def stop_pump():
    p["status"] = "Зупинено"

display = ui_display.create()
ui = ui_main.UI(display)
p = dict(ui_main.DEFAULTS)
ui.draw(p, actions={"start_pump": start_pump, "stop_pump": stop_pump})
ui.listen_touch()                         # далі дотики обробляються у фоні
```

Якщо якоїсь процедури з редактора в мапі немає, `draw()` одразу скаже, якої саме.
Після процедури сторінка сама перемальовує те, що змінилося в `p`. Натискання ловить верхній
елемент із «При натиску»; схований умовою — не ловить. Функції мають бути короткими (поки
одна працює, сенсор не читається). Свій код, що теж користується шиною SPI (наприклад,
SD-карта, яку ви підключили самі), загорніть у `with ui_draw.Busy():` — тоді дотик не
втрутиться посеред нього.
`ui.stop_touch()` — перестати слухати; `ui.hit(x, y)` — id елемента під точкою.

Згенерована тека лежить будь-де на платі й підключається як пакет (`from ui.main import …`); у корені
плати її файли імпортуються й напряму (`import ui_display`). Наступна генерація в ту саму папку
замінює файли сторінки новими.

## Якщо щось не так

- **Чорний екран** — піни в **Дисплей…** не збігаються з підключенням, або порт тримає інша програма.
- **«Негатив» або переплутані червоний і синій** — «Інверсія кольорів» / порядок кольорів (RGB/BGR).
- **Сірий прямокутник замість картинки** — на плату не залито теку `img/`.
- **`MemoryError`** — зменште буфер області й кеш картинок у **Дисплей → Пам'ять**, великі анімації
  чи кількість розмірів шрифтів.
- **Плата перезавантажується по колу** — у `main.py` помилка до малювання: перехопіть старт Ctrl+C у
  консолі й подивіться повідомлення.
